### 🤖 Projet phare : le robot Léo

<a href="https://github.com/ilyasdevelop/sae2-robot-leo">
<img src="https://raw.githubusercontent.com/ilyasdevelop/sae2-robot-leo/main/docs/robot_leo.jpg" width="320" align="right" alt="Robot Léo">
</a>

Robot autonome construit à trois pour la coupe de robotique du département GEII (SAÉ2, 2026).
J'étais responsable de deux parties :

- **le cerveau :** une machine à états sur ESP32 qui cherche une balise infrarouge, contourne les obstacles et s'arrête sur la zone d'arrivée ;
- **l'énergie :** une carte d'alimentation sans batterie, avec deux supercondensateurs de 200 F équilibrés par un AOP, conçue sous KiCad puis brasée et testée.

➡️ [Voir le dépôt](https://github.com/ilyasdevelop/sae2-robot-leo)
